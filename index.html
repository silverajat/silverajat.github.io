RTL verified · board ordered

Crypto order-flow engine on my own Zynq-7020 board

A Verilog engine that takes live exchange data over Ethernet, rebuilds the order book in hardware and computes trading signals, with a PicoRV32 RISC-V control CPU and a hardware risk gate.

  • Hardware price-time matching engine: all 102,044 events of a 69-minute real-data stream identical to the C++ engine
  • Tick-ladder order book cut packet-to-features latency from 8.8 to 3.4 µs (p50) and 53.5 to 7.6 µs (p99)
  • Hardware timestamps match the pins to 10 ns; on-chip latency histograms
  • Designed the 6-layer Zynq-7020 board with DDR3L to run it

Approach

Golden model first, then hardware

Write the reference

A C++ or Python model of exactly what the hardware should do, tested on its own before any RTL exists.

Prove it on real data

cocotb testbenches replay real recordings through the RTL and compare every value against the model: market data, gym sets, audio.

Then build the board

Only then the PCB: schematic, layout, fab files, bring-up. When something breaks, I write down why.
